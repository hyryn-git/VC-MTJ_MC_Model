# Field-Free VC-MTJ Monte Carlo Model

A field-free VC-MTJ Verilog-A model that captures hybrid dynamics and supports Monte Carlo simulation in Cadence Virtuoso and Spectre.

## Repository Contents

* `0_VC_MTJ_Model/`: Complete model package, including the Verilog-A model and schematic- and netlist-based testbenches.
* `Manual_Field_Free_VC-MTJ_v1.0.pdf`: User manual for model setup and simulation.

For installation, file organization, and simulation instructions, see [`0_VC_MTJ_Model/README.md`](0_VC_MTJ_Model/README.md).
